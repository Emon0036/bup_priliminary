# Security Policy

## Reporting a Vulnerability

If you discover a security vulnerability, please send an email to the maintainer at **Emon0036**. We will acknowledge your report within 48 hours and provide a timeline for fixing the issue.

Please do **not** report security vulnerabilities through public GitHub issues or discussions.

## Supported Versions

| Version | Supported          |
| ------- | ------------------ |
| Latest  | :white_check_mark: |
| Older   | :white_check_mark: |

## Security Updates

Security patches will be released promptly after a vulnerability is confirmed. We recommend keeping your dependencies up to date.

## Guidelines

- Do not exploit vulnerabilities for personal gain
- Give the maintainer reasonable time to fix the issue before public disclosure
- Be respectful and cooperative throughout the process
